# HW1
This folder contains the HW1, problem 1, linear regression model. This linear regression model uses the data sampregdata.csv file from the data folder for evaluations. The evaluation of this model uses the scikit-learn library, specifically the linear regression and r2 model. The current version uses a two variable approach using the x3 and x4 columns to achieve an r2 score of ~.53. The previous model, which can be accessed in the git commit history, used only one variable, the x4 column, and achieved an r2 score of ~.27.
